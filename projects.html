My web development project

Personal Portfolio Website

This project presents my background, skills, goals and learning journey through a professional multi-page website.

1. Project Overview

The purpose of this project is to create a personal website that introduces me and displays my development knowledge. The website uses separate pages connected through a navigation menu.

Project Objectives

  • Introduce myself and my career goals.
  • Present my skills and learning progress.
  • Practise HTML page structure.
  • Use CSS for colours, borders, fonts and layout.
  • Connect pages using working navigation links.
  • Make the website readable on computers and phones.
